# 개인용 할 일 관리 웹앱

## 문제
혼자 쓰는 사용자가 할 일을 기록·추적할 도구가 없다. 할 일을 적고, 끝낸 것을 표시하고, 기한을 챙길 수 있는 가벼운 웹앱이 필요하다.

## 원하는 결과
- 브라우저에서 할 일을 입력하면 목록에 바로 나타난다.
- 할 일을 완료 체크/해제할 수 있고, 완료된 항목은 시각적으로 구분된다.
- 할 일을 삭제하면 목록에서 사라진다.
- 기존 할 일의 제목을 수정할 수 있다.
- 필터(전체/진행/완료)를 선택하면 해당 상태의 항목만 보인다.
- 할 일에 마감일을 지정할 수 있고, 목록에 마감일이 표시된다.
- 서버를 재시작한 뒤에도 목록이 그대로 남아 있다.
- `curl -s localhost:3000/api/todos` 가 할 일 목록을 JSON으로 반환한다.

## 영향 받는 사용자·시스템
- 사용자: 단일 사용자 1명 (로그인·계정 없음)
- 시스템: `src/` Node 서버(`node:http`), `public/` 정적 프론트엔드, 로컬 파일 저장소

## 제약
- npm 의존성 추가 금지, Node 내장 모듈만 사용 (Node 24, ESM)
- 데이터는 로컬 파일(JSON)에 저장
- 인증·다중 사용자 지원은 범위 밖

## 열린 질문

- 목록 정렬 기준 (생성순 / 마감일순)?
- 제목 최대 길이, 빈 제목 처리 규칙?
- 데이터 파일 위치 (예: `data/todos.json`)와 git 추적 여부?
