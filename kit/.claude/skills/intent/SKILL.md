# Intent 작성

목표: 사람이 읽을 수 있고 다음 단계(spec)가 그대로 읽어 쓸 수 있는 `intent/<slug>.md`.

1. 범위를 잡는 질문을 **한 번에 최대 3개** 한다. 답이 이미 요청에 있으면 묻지 않는다.
   - 누가 쓰는가 / 지금 무엇이 불편한가 / 완료를 어떻게 알아보는가
2. `templates/intent.md` 양식으로 초안을 작성한다. 모르는 것은 지어내지 말고 "열린 질문"에 남긴다.
3. 원하는 결과는 관찰 가능한 형태로 쓴다 ("편하다" ✗ → "새로고침해도 목록이 남는다" ✓).
4. 사용자에게 초안을 보여주고 수정받는다.
5. 사용자가 승인하면 `status: accepted`로 바꾸고 `intent: <slug>` 메시지로 커밋한다.

다음 단계: `spec` 스킬.
